# 🚀 Portfólio Front-End — DevInEvolution

Bem-vindo ao meu portfólio!  
Este projeto foi desenvolvido com foco em **design moderno**, **experiência do usuário** e **boas práticas de desenvolvimento front-end**.

Aqui você encontra meus principais projetos, tecnologias que utilizo e um pouco da minha evolução como desenvolvedor.

---

## 🧑‍💻 Sobre mim

Sou um desenvolvedor **Front-End em constante evolução**, apaixonado por transformar ideias em interfaces funcionais, acessíveis e visualmente agradáveis.

Minha jornada na programação começou através de um curso onde me destaquei entre os melhores da turma, o que abriu portas para experiências profissionais relevantes, incluindo atuação em projetos reais, resolução de bugs e criação de interfaces alinhadas a layouts profissionais.

Acredito que **constância, dedicação e aprendizado contínuo** são a base para crescer na área de tecnologia.

## 🖥️ Sobre o projeto

Este portfólio foi criado para:

- Apresentar meus projetos pessoais e profissionais
